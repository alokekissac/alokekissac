## ⚡ How I Work

> *"A model isn't done when the loss goes down. It's done when it beats a sensible baseline on data it has never seen, and someone can actually use it."*

</div>

<table width="100%">
  <tr>
    <td width="33%" valign="top">
      <h4>📏 Baselines first, honest metrics</h4>
      <sub>Every model is compared against simple baselines and, where possible, the exact optimum. Results come from held-out data and multiple seeds, and I report them even when the simple model wins.</sub>
    </td>
    <td width="33%" valign="top">
      <h4>🚀 From notebook to product</h4>
      <sub>Research ends up as something usable: a Flask API with input validation, a web app or dashboard, and a one-click Vercel deploy.</sub>
    </td>
    <td width="33%" valign="top">
      <h4>🧩 Reproducible by default</h4>
      <sub>Seeded training scripts, saved models, tests, executed notebooks and READMEs that explain the method, the results and the limitations.</sub>
    </td>
  </tr>
</table>
